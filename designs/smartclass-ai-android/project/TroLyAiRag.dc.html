HỌC SINH HỎI · 14:20 Sự khác nhau giữa Abstract Class và Interface trong Java là gì? Khi nào nên dùng Interface?
PHẢN HỒI TỪ GIÁO TRÌNH LỚP MỨC ĐỘ: {{mucDoHienTai}}

1. Abstract Class cho phép khai báo cả thuộc tính trạng thái (state), hàm khởi tạo (constructor) và phương thức đã cài đặt sẵn; một lớp chỉ kế thừa đơn (extends) một Abstract Class.

2. Interface định nghĩa bản hợp đồng hành vi; một lớp có thể thực thi (implements) nhiều Interface cùng lúc để tách rời giao diện khỏi cài đặt.
